Nikon N-RAW (.nev) to 12-Bit Apple ProRes 4444 & N-Log Studio

A zero-FFmpeg native Rust, Apple Metal, and VideoToolbox studio & CLI for grading Nikon Z8 / Z9 RAW video in scene-linear light (Kelvin, Tint, Exposure, 3D LUTs & RGB Scopes) before encoding 12-bit ProRes 4444 with Final Cut Pro FCPXML v1.11 metadata.

4-Stage Native Apple Silicon Pipeline

Every stage runs directly on macOS system frameworks using Unified Memory zero-copy sharing between CPU performance cores, the Apple Metal GPU, and the dedicated ProRes Media Engine.

STAGE 01 • DEMUX & NCDT

64-Bit ISO-BMFF & Nikon MakerNote

Zero-copy co64 box walker for multi-gigabyte 8K60 .nev files. Extracts embedded NCDT As-Shot White Balance (0x000C), optical Black Level (0x003D), ISO, shutter angle, 24-bit PCM audio, and SMPTE tmcd timecode.

STAGE 02 • RAYON CPU POOL

Bounded TicoRAW Bitstream Pipeline

Parallel frame unpacking across Apple Silicon P-cores using a bounded ring buffer so RAM stays flat even on 100+ GB 8K clips, with optional NEV2PRORES_TICORAW_DYLIB C ABI plugin loading.

STAGE 03 • METAL COMPUTE

5×5 Debayer, Bradford WB & Official N-Log

Shared-memory FP32 Metal compute shader executing Malvar-He-Cutler demosaicing, neutral highlight reconstruction, scene-linear Exposure & Bradford chromatic adaptation into ITU-R BT.2020, and continuous Nikon N-Log encoding.

STAGE 04 • VIDEOTOOLBOX

12-Bit ProRes 4444 & FCPXML v1.11

IOSurface-backed VTCompressionSession encoding for ProRes 4444 (ap4h) and 422 HQ (apch), muxed with Rec. 2020 colr (9-1-9), 24-bit little-endian PCM audio (wave/enda), tmcd, and Final Cut Pro XML sidecars.

STUDIO UI • SCOPES & LUTS

Per-Clip Grading, Scopes & .cube LUTs

Interactive 60 fps GPU viewport with per-clip Kelvin/Tint/EV memory, one-click Copy Grade to All, non-destructive 17³/33³/65³ .cube 3D LUT trilinear preview, 64-bin RGB N-Log histogram scopes, and highlight zebras.

QUALITY • VERIFIED CI

Hardware Round-Trip Tested

Every pull request is verified on Apple Silicon runners with VTDecompressionSession ProRes round-trip golden accuracy assertions, highlight neutrality checks, and malformed container fuzzing.

Install & Command-Line Quickstart

Open nev2prores.dmg and drag nev2prores.app into Applications, or build directly from Rust source with Cargo.

1. Build & bundle from source (Rust 1.88+ on macOS Apple Silicon):

git clone https://github.com/adrienledoux-dev/nev2prores.git
cd nev2prores
./scripts/bundle_macos_app.sh
cp -R dist/nev2prores.app /Applications/

2. Batch transcode a card folder to 12-bit ProRes 4444 + Final Cut Pro FCPXML v1.11:

/Applications/nev2prores.app/Contents/MacOS/nev2prores \
  --input /Volumes/NIKON_Z9/DCIM/100NCZ_9 \
  --output ~/Movies/ProRes_Masters \
  --codec prores4444 \
  --kelvin 5600 \
  --ev 0.35 \
  --fcpxml
First-Launch Note for Unsigned Community Builds

If a release was built before Apple Developer ID notarization secrets were enabled, macOS Gatekeeper may pause on first launch. Clear the quarantine flag once in Terminal (or see our macOS Code Signing & Notarization Guide): 

xattr -dr com.apple.quarantine /Applications/nev2prores.app
